# CalcForge-CPP

A modular C++ console calculator designed with
function-based architecture and basic error handling.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Remainder
- Division-by-zero handling
- Interactive menu
- Reusable functions

## Tech Stack
- C++
- Standard Library
- Console-based application

## Key Concepts
- Functions
- Loops
- Conditional Statements
- Data Types
- Input/Output
- Error Handling

## How to Run

Compile:
g++ calcforge.cpp -o calcforge

Run:
./calcforge
